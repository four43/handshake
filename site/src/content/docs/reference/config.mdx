The server reads `config.toml` from the path in the `CONFIG` environment variable (the image uses `/etc/handshake/config.toml`). Secrets never go in this file:

| Variable | |
| --- | --- |
| `SESSION_SECRET` | Required, 32+ characters. Signs session tokens. |
| `SESSION_SECRET_PREV` | Optional. Also accepted when verifying, so you can rotate the secret without logging everyone out. |
| `TURN_SECRET` | Must match coturn's `static-auth-secret`. Needed when `[turn]` is set. |
